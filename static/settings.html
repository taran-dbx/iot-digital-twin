Latency Metrics Explained

MetricDescription
Write Latency Time for the sink's write operation to complete (e.g., PostgreSQL INSERT round-trip, Zerobus gRPC ack). Measures just the I/O portion.
E2E Pipeline Latency Time from when the simulator generated the record to when the write completed — includes buffer queueing time + write time. This is the true end-to-end delay a downstream consumer would experience.
P95 95th percentile — 95% of operations complete faster than this value. Useful for understanding worst-case latency experienced by most records.
Throughput Records successfully written per second. Affected by flush rate, batch size, and write latency of the destination system.
