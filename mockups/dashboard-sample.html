Historical analytics unavailable — Lakebase Sync (CDF) is not enabled

The cold tier is a Unity Catalog managed table that Lakebase CDF streams from the lakets_cdf schema. Until the sync is STREAMING, DBSQL historical queries return nothing. Enable it once in the Databricks UI:

  1. Lakebase project → Branch overview → CDF
  2. Start sync, select lakets_cdf
  3. Set destination UC catalog + schema, then start

Status: SELECT status FROM wal2delta.tables; → SNAPSHOTTING → STREAMING. Populates automatically once streaming.
